Publish web adalah cara untuk mempublishkan web statis ataupun dinamis yang sudah kita buat agar dapat dilihat oleh user melalui browser. Agar dapat diakses oleh user unutuk membuat website, kita juga memerlukan sebuah domain dan hosting.

Bagi anda yang belum tau apa itu domain, singkat cerita domain adalah sebuah nama alamat yang nantinya akan digunakan user untuk mengakses, melihat atau menampilkan halaman web kita.

Domain diatur sedemikian rupa sehingga memudahkan kita dalam mengakses sebuah webserver, karena kita tidak pelku lagi menuliskan alamat sebuah webserver alam bentuk IP address.

Berikut cara mempublish website anda:
  1. Mendapatkan domain
  2. Menentukan nama server di domain
  3. Mendapatkan hosting
  4. Mengupload website
  5. Install database (jika diperlukan)
  6. Testing hasil
